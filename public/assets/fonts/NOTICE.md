# UI fonts

- Permanent Marker Regular, from Google Fonts: https://github.com/google/fonts/tree/main/apache/permanentmarker . Apache License 2.0, included in PermanentMarker-LICENSE.txt.
- Kalam Bold, copyright 2014 Indian Type Foundry: https://github.com/google/fonts/tree/main/ofl/kalam . SIL Open Font License 1.1, included in Kalam-OFL.txt.

Modified for this game: subset to basic Latin UI text and selected punctuation, converted from TTF to WOFF with fontTools. Font outlines and attribution metadata retained. Files are self-hosted, with no runtime requests to external font providers.
