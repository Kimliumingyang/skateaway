# 待补素材清单

本轮按两份 PDF 落地了现有素材可支持的 P0。以下缺图对象没有用别的图片冒充，也没有加入正式随机生成。

## 本次聊天素材等待原文件

主页新人物、星形图案、气球、海鸥已在聊天展示，但没有可下载的原文件。请将这 4 张原图打包为 ZIP 上传，才能原样替换、加入运行素材并发布。招牌与裂缝已找到现有同款原图，不必重复上传。以下清单中的 Star / 气球 / 鸟因此仍未进入游戏。

## 建议优先补充

| 素材 | 用途 | 建议交付 |
|---|---|---|
| 星星 Star | 护盾 + 金币吸引 | 透明 PNG；如有，附护盾/磁吸启用、持续、结束特效 |

| 滑行、落地、Kickflip | 替换现有角色图片的程序摆动 | 同一角色、同尺寸透明帧，附帧顺序/时长及脚底锚点 |

## 已有，不必重复上传

金币、火箭、能量石（Gem，**不是 Star**）、路锥、纸箱、香蕉、警示牌、裂缝、可站招牌/空调、建筑与背景。
你上传的 **摔倒、一段跳、二段跳 APNG 已经接入**，无需重传。滑行、落地和 Kickflip 仍使用单帧图与程序反馈。

## 上传方式

可直接在聊天里上传 PNG、APNG、精灵表或 ZIP。序列帧建议命名 `jump_001.png`、`jump_002.png` 等，每帧画布尺寸一致、透明背景；标注动作名称、顺序和总时长即可。没有时长也可以先提供原文件，再一起调试。请保留原始分辨率，不必为 1920×1080 画布强行拉伸图片。

完整规则、冲突决策及暂缓内容见 [玩法对照](GAMEPLAY_SPEC_RECONCILIATION.md)。广告需要实际 SDK 配置，不能仅靠一张图片完成；本轮没有模拟广告或开放金币复活。
