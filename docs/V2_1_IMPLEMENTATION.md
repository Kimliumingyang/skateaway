# SkateAway 2.1 · 实现记录

依据上传的 `2.1.pdf` 以及三份动画 ZIP，沿用 2.0 的 1920×1080 Phaser 游戏。文档中的 P0 是本轮实现范围；另接入了 P1 的气球单次弹跳。原始 `Asset.zip` 未解压或改写。

## 当前可玩内容

- 首轮建筑固定为 `1 → 2 → 4 → 3 → 5 → 6 → 4 → 7 → 6 → 8`；后续按十栋模板循环。楼体继续使用原图且保持比例，屋顶碰撞面与视觉比例分别配置。窄楼入口按跳跃速度留出前墙净空，单跳可跨越验证过的楼间隙；CYBER 招牌与第一栋 4 号楼上有额外可站立教学平台。
- Rookie Challenges 七项按首轮关键事件依序解锁，奖励只记录一次，在下一次 Run Ended 结算。每局从文档的 12 项 Street Missions 中分配一个 Easy 和一个 Skill 目标，进度自动更新；连续跨越与无惩罚建筑任务会在受罚时重置连续计数，已完成任务不会撤销，奖励只结算一次。七项 Street Legends 按实际跳跃、金币、跨楼、特技及单局表现累计并永久解锁。存档增加独立的最远距离、最长存活和最佳 Combo 记录，已有存档兼容。
- 新上传的八帧二段跳动画只在第二次空中跳跃播放；落地、撞击与重试清理视觉状态。海鸥按低频、固定预告位置飞过，身体核心碰撞导致 `SEAGULL` 死亡原因；气球上下漂浮，下降踩中主体时弹一次，播放 Shake → Pop。绳子及翅膀边缘不参与碰撞。首次十栋教学楼不生成这些动态物件。离屏和死亡时清理临时对象。
- 主菜单的 Street Challenges 按钮可查看新手挑战、下一局任务、长期成就和个人最佳；暂停页显示当前两个任务，并可打开任务面板。结果页区分本局拾取金币、任务奖励和 Rookie 奖励，还显示任务完成状态、解锁成就与新纪录。榜单页显示独立个人最佳记录。

## 本轮边界

PDF 的互动 P1 后续项（Coin Thief 海鸥、气球掉落金币、海鸥撞气球事件）与 P2 项尚未接入。现有的贴图和状态机已经为继续迭代留出接口。4 号楼的内部各层仍是视觉建筑，当前只新增一处上层教学平台；其余内部可玩楼层需要单独测量原画与规划连接后再开放。

## 验证

运行 `npm run check` 与 `npx playwright test`。物理测试包含十栋固定顺序、万段生成边界及不同滑行速度下的单跳着陆；浏览器验证包括触屏/键盘二段跳、任务唯一结算、海鸥死亡原因、气球单次弹跳、撞击动画和重试清理。开发预览可运行 `npm run dev`；发布预览以最终 GitHub Pages 部署结果为准。
