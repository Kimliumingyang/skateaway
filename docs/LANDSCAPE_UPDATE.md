# 横屏、角色与落地建筑更新

本轮按用户的新方向取代原先的竖屏目标，画布、菜单、HUD、暂停、设置、排行、结算均改为 1334×750 横屏，手机竖放时保留等比画面并提示旋转。

角色使用用户新提供的正面滑板人物参考图，经图像编辑工具去白底形成单帧 RGBA 素材；保留帽子、服装和整块滑板。处理结果保存在 Asset/Characters/character-cutout.png，运行时副本为 public/assets/character.png。渲染时裁去透明边距，角色高度 132px，轻微摆动/跳跃倾斜为程序反馈，并非新画出的逐帧动画。

建筑 2/3/6/7 统一以 y=700 为底线。WorldConfig.ts 记录素材的高度、台面位置、台面宽度；由目标屋顶高度计算同一缩放比例及平台宽度，保持原始建筑比例。不同楼顶在 y=330–470 之间变化，单次向上高度差不超过 65px。主角跳跃、金币、障碍与实际台面位置保持一致。短屋顶不放置无法留出反应空间的障碍。落到街面或撞上高楼侧面会结束本局。

验证：npm run build 成功（保留 Phaser 大 chunk 提示）；6 项物理/生成测试通过，包括 10,000 段生成约束、500 段建筑底部和台面对齐、1,000 次实际物理跳跃落地及高楼侧面净空；桌面 1440×900 和横屏手机 844×390 浏览器流程通过，包含双跳/第三跳限制、触摸、暂停恢复、设置保存、金币、障碍死亡、重试与自然失败。浏览器也验证所有活动建筑图像底部为 y=700、角色纹理为 character。

预览继续通过 GitHub Pages 的 main:preview/ 发布；游戏源码保留在 feat/playable-skateaway / PR #1。仍需正式角色动画与真机长期手感测试。
