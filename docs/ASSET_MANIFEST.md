# Asset manifest

Original sources and Asset.zip remain unchanged. All 44 PNGs were visually reviewed in a contact sheet; no sprite sheets or independent transparent character/animation frames exist. Menu artwork includes a flattened character and title, used only as menu decoration. Gameplay uses a labeled procedural temporary skater, never cropped from the menu. All image assets are single frames. Runtime copies retain source aspect ratios. Phaser scales large backgrounds to fit height; buildings use uniform scales with a supplemental neon collision ledge. No original art is edited.

Cyan Kickflip is the selected looping supplied soundtrack. Other two tracks remain unused. Jump/coin/landing/death SFX are synthesized, not supplied recordings. Revive artwork includes a baked-in ad badge and 300 cost, so is deliberately unused. Revives are deferred. Panels are decorative with real interactive controls and live values.
